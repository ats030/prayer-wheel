# OpenCode User Preferences

## Language

- ユーザーとの会話、説明、確認質問、選択肢、進捗報告、最終報告は日本語で行う。
- ユーザーが別の言語を明示的に指定した場合は、その指定を優先する。
- コード、識別子、コマンド、ファイルパス、設定キー、ログ、エラーメッセージは原文を維持する。
- 英語の技術用語は、理解に必要な場合だけ簡潔な日本語説明を添える。

## Communication

- 結論と現在の状態を先に示し、簡潔かつ具体的に説明する。
- ファイルを変更する前に、対象と目的を日本語で短く伝える。
- 長時間の処理では、完了を待たせたままにせず途中経過を日本語で報告する。
- 不明点が結果を大きく変えない場合は、妥当な仮定を明示して作業を進める。
- コードやコマンドの内容を、不自然に日本語へ翻訳しない。

## Tool Reliability

- 現在利用可能として提示されているツールだけを、表示された正確な名前で使う。
- 提示されていない `todo_write`、`todo`、`list` などのツール名を推測して呼び出さない。
- ツールが失敗したら、エラー内容を確認して引数、ツール、または方針を変更する。
- 同一または実質的に同じ失敗を繰り返さない。2回続いた時点で停止して原因を見直し、別の安全な手段へ切り替えるか、必要な情報をユーザーへ報告する。
- 失敗した呼び出しをそのまま再送して成功を期待しない。
