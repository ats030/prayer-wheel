# お経の選択

## 公開する内容

- 般若心経: 既存29節・合成音声・独自意訳を維持。
- 観音経（偈文）: 「世尊妙相具」から「是故応頂礼」まで520字を52節に分割。後続の散文を含む普門品全体ではありません。

古典の本文を現行字体で独自に入力し、伝統的な字音を文字単位で指定しました。
読み方や解釈には宗派による違いがあり、特定宗派の公式な唱え方ではありません。
意訳はこのアプリ用にAIが草案を作り、原文との対応を点検したものです。僧侶による監修は受けていません。
観音経中の災難を免れる描写は経文の意訳で、事故・病気への安全や効能を保証するものではありません。
現代の解説文・現代語訳・楽曲・録音・NHKの編曲は転載していません。

## 出典と権利

漢訳古典そのものは保護期間の満了した本文です。伝統的な字音を現代仮名で表し、近現代の版面・画像・解説・音源は使用しません。
下記は古典本文・通常の字音・偈文の範囲を確認するための参照先です。

- [臨黄ネット「経典」](https://rinnou.net/about/scripture/) — 偈文が「世尊偈」「普門品偈」として独立して唱えられることの確認。
- [明治大学・加藤徹「観音経」](https://www.isc.meiji.ac.jp/~katotoru/okyou-kannon.html) — 古典本文と伝統的な字音の照合。掲載された独自の解説・現代語訳・編曲を使うものではありません。

## データと音声

`data/kannon.json`が本文・読み・文字別の字音・独自意訳の原本です。
`python3 scripts/kannon-audio.py --generate`で既存のVOICEVOX 0.25.2を利用して音声を事前生成します。
明示カナの解析により漢字の読みの推定を避け、既存と同じWhiteCUL・波音リツ、音高・拍・休符・音量調整を使います。
長音は文字ごとに既存の文字タイミング検証と同じ正規化を適用します。文字の境目の「諸（しょ）＋有（う）」を長音に変えないようにしています。
`audio/kannon-manifest.json`は入力ハッシュ、合成スコア、音素、WAVハッシュを保存します。
原文・各文字の読み・合成音素・WAVの長さとハッシュ・音割れを`python3 scripts/kannon-audio.py`で検証します。
音声の利用条件は[audio-license.yaml](audio-license.yaml)です。

## 切替と失敗時の動作

選択欄は`app.js`に定義した同一オリジンの固定2種類だけを読み込みます。
切替時は旧プレイヤーを停止してイベントを解除し、予約・文字位置・操作数・巡数を初期化します。
進行の永続保存や外部への送信は行いません。速度とdetailsの開閉状態は維持します。
以前の読み込みは中止し、遅れて結果が返っても最後の選択を上書きしません。
失敗時はマニ車を無効化し、選択中のお経を再読み込みできます。

ビルドは両経文の原本ハッシュと文字・音声の対応を確認し、音声を内容ハッシュ付きURLで配信します。
音声生成メタデータや設定は公開しません。停止・巻き戻しは従来のキー操作を維持します。

## 検証と復帰

- `npm test`
- `python3 scripts/kannon-audio.py`
- `python3 scripts/check-browser.py --url <配信URL>` — 既存般若心経の実再生・予約・逆行・復旧・5幅。
- `python3 scripts/check-sutra-switch.py --url <配信URL>` — 切替、旧イベント、読み込み競合と再試行、観音経の実音声、全52節の本文・意訳・文字対応と5幅。
- `python3 scripts/check-cloudflare.py --url <公開URL> --package dist-pages` — 全公開ファイル・MIME・ハッシュと非公開パス。

変更コミットをrevertし、通常のbuild・deployを行えば般若心経のみの画面に戻せます。
