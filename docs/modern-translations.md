# 現代語訳（意訳）

`modern-translations.js`は、既存の古典本文`data/sutra.json`の29節に対応する、このアプリ用の意訳です。
既存の現代語訳の転載ではありません。2026-10-15にAIによる草案として作成し、原文との対応を点検しました。
宗派の公式訳や僧侶の監修を受けた訳ではありません。

## 方針

- 原文・読み仮名・音声は変更せず、実際に読み上げを開始した一節に対応させます。
- 「空」は単なる不存在や虚無とせず、固定した独立の実体を持たないという意味で説明します。
- 「無」の列挙は、身体や苦しみの経験自体が存在しないという断定にせず、実体への執着を離れる文脈で訳します。
- 五蘊は身体・感覚・表象・意志・認識の働きとして補います。「思考」は短い表示のための概括です。
- 2–3節、16–17節、20–21節などは意味が次の節へ続きます。原文の区切りを維持しています。
- 真言（27–28節）は解釈の一例です。音写の訳は一義的に確定するものではありません。
- 「苦しみを取り除く」などは経文の意味を示すもので、アプリの効能の保証ではありません。

## 照合に用いた資料

古典本文はアプリの既存データを使用しています。本文・語義の確認に以下を参照しました。
現代語の文面は独自に作成し、参照先の訳文・解説文は転載していません。

- [寺尾寺「般若心経」](https://www.eonet.ne.jp/~terao-ji/okyo_ha1.htm) — 漢文本文と構成の照合。
- [新纂浄土宗大辞典「色即是空空即是色」](https://jodoshuzensho.jp/daijiten/index.php/色即是空空即是色) — 「色」と「空」を切り離さないことの確認。
- [曹洞宗「経典」](https://www.sotozen-net.or.jp/soto/sutra) — 般若心経の位置づけ。

## 検証

`npm test`で原文全節とのキーの一致を確認します。
ブラウザ検証では初期・再生・次節・逆行・リセット時の対応と、320–1280pxで長い訳文の収まりを確認します。
訳は原文の文字列で対応づけているため、節の順番が変わっても別の訳へずれません。
