読経の試聴

「観自在菩薩」から5節を聴き比べます。A・Bは同じ声、C・Dは声と発声方法を変えた試作です。アプリ本体はD（WhiteCUL）の発声を採用しています。

A · 旧版の読み上げ

本体変更前のNemo音声を5節続けたもの。区切りと抑揚を比較する基準です。

現行音声を保存

B · 拍を整えた試聴版

語の区切りを保ったまま間を短くし、抑揚と母音の長さのばらつきを抑え、節間を短くしています。

試聴版を保存

C · 母音を伸ばす低音の試作

低めの単独声で母音を持続させ、長いまとまりの終わりで音を伸ばして息継ぎの間を置きます。短い句はつなぎ、声だけで比較します。

低音の試作を保存

Cの声: VOICEVOX:麒ヶ島宗麟

D · 採用した女性の発声

本体に採用した発声です。Cと同じ拍・息継ぎの位置で、女性の声を比較します。音域はCより高めにしています。

女性の試作を保存

Dの声: VOICEVOX:WhiteCUL

再生ボタンで聴き比べられます。

聴くポイント

母音の伸び、声の低さ、息継ぎのまとまりを比べてください。C・Dは声と生成方式も変わるため、間の調整だけの比較ではありません。平坦すぎる、速すぎる、聞き取りにくい箇所も判断の材料になります。

  1. 観自在菩薩
  2. 行深般若波羅蜜多時
  3. 照見五蘊皆空　度一切苦厄
  4. 舎利子　色不異空　空不異色
  5. 色即是空　空即是色

A・Bの音声: VOICEVOX Nemo（男声1）

C: VOICEVOX:麒ヶ島宗麟 / VOICEVOX:波音リツ（歌唱クエリ生成）

C音声を再利用する際は上記クレジットを表記し、VOICEVOX規約、VirVox規約、波音リツ規約を守ってください。

D: VOICEVOX:WhiteCUL / VOICEVOX:波音リツ（歌唱クエリ生成）

D音声を再利用する際は上記クレジットを表記し、VOICEVOX規約、WhiteCUL規約、波音リツ規約を守ってください。

参考: 全国曹洞宗青年会の読経練習用動画。参考録音は同梱していません。

合成音声の調整案です。僧侶の録音や、特定宗派の節回しを再現したものではありません。
