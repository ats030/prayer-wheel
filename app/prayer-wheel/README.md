# 経文回向ホイール（prayer wheel）

マウスホイールを回すと**心経**（既定）の一行が読み進み、
読み上げた行数に合わせて輪が30°ずつ回っていく、静的なウェブアプリです。
サーバ不要・外部依存なし。音声はブラウザの Web Speech API
（`speechSynthesis`）で読み上げます。

## 動作方法

静的ファイルを配信するだけで動きます。

```bash
cd app/prayer-wheel
python3 -m http.server 8731 --bind 127.0.0.1
# http://127.0.0.1:8731 を開く
```

## 操作

| 操作 | 効果 |
|---|---|
| ホイールを**下**へ回す / ホイール部分をクリック | 一行進む（輪が30°回転、1回カウント） |
| ホイールを**上**へ回す / `↑` / `PageUp` | 一行戻る（前回分を取り消して1行戻る） |
| `↓` / `PageDown` | 一行進む |
| `Space` / 「一時停止」ボタン | 読み上げを一時停止・再開 |
| 「最初から」ボタン | 行数・輪の回転・読み上げをすべて初期状態に戻す |
| 速度スライダー | 読み上げ速度 0.6×–1.4× |
| 音声セレクタ | 読み上げ音声を選択（日本語音声がある環境） |
| .txt ファイル選択 | 任意の経文テキスト（句点・読点で分割）を読み込む |

- 1回のホイール操作あたり約120単位（`deltaY`）の集計で1回分とカウントします。
- 読み上げキューが溜まった（上限5件）状態でホイールを回すと、
  「ごゆっくり — 朗読が追いついておりません」と表示され、その回の
  回転は受け付けません。読み上げが追いつくとまた回せます。

## 仕様メモ

- **経文の区切り**: `、。；！？,!?;` で分割し、連続する短い節を
  約15文字以上のチャンクにまとめて読み上げます。長文を一発で読み上げると
  途中で休止になるChromeの挙動を回避するための粒度です。
- **音声の依存**: 読み上げる音声はブラウザ/OSで登録されているものを
  使います。日本語音声がない環境ではバナーが表示され、読み上げは
  行いません（行数・輪の回転は続きます）。
- 行番号は `1 / N 節目` の形式で表示されます。
