## 抽出方法と判定基準

候補判定表で `status == "hold"` の88件を母集団とした。
各 `source_id` に `ats030-jt66-2026-09-23|` を前置してUTF-8でSHA-256を計算し、
16進ダイジェスト昇順の先頭12件を抽出した。抽出後に対象を選び直していない。
再現には次を使える。

```bash
python3 -c 'import json,hashlib; d=json.load(open("app/shiseki-map/docs/public-candidate-review.json")); r=[x for x in d["records"] if x["status"]=="hold"]; print("\n".join(x["source_id"] for x in sorted(r,key=lambda x:hashlib.sha256(("ats030-jt66-2026-09-23|"+x["source_id"]).encode()).hexdigest())[:12]))'
```

「現行根拠あり」は照合日に自治体・国の公開ページで名称や所在地を確認できた意味で、
そのページの情報が当日更新された意味ではない。「訪問案内あり」も、敷地内立入り、
墓所への立入り、営業時間の保証ではない。重複は既存地図との同一対象に限る。
重大誤りは、候補をそのまま独立した訪問地点として追加すると誤案内になることが
一次資料で確定した場合とした。
