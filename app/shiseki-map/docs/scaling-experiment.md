# 3万件化オフライン実験

Issue: `ats030-1is6`

## 目的と範囲

公開データを変更せず、QID非依存の正本、根拠、外部ID、保留候補を分離した
SQLiteスキーマが成立するかを検証する。また、3万件時の検索クエリ性能を測る。

この実験は新しい収集元の供給量を証明するものではない。全面移行や公開可否の
判断には、再利用可能な公的データの実数調査が別途必要である。

## データ源の判断

- Wikidata: CC0。現行スナップショットをスキーマ検証に使用する。
- 国指定文化財等データベース: 文字情報は出典表示条件で候補とする。
- ジャパンサーチ: 連携DBごとのAPI取得可否と権利条件を満たすレコードのみ候補とする。
- 国土数値情報 P32: 非商用条件のため、アフィリエイト導線のある本サイトでは不採用。
- 自治体オープンデータ: 自治体・データセット単位で商用利用、再配布、出典表示を審査する。

詳細は `docs/tool-license.yaml` に記録する。

## 再実行

```bash
cd app/shiseki-map/scripts
python3 -m unittest -v test_scale_experiment.py
python3 scale_experiment.py \
  --output /tmp/shiseki-scale-pilot.db \
  --report /tmp/shiseki-scale-report.json \
  --target 30000
```

計測値はこの稼働環境での一実行例であり、SQLite直接クエリの時間のみを示す。HTTP、JSON変換、ブラウザ描画を
含まない。したがって、サーバー側の絞り込みは十分速いと言えるが、2秒以内の
ユーザー操作を証明するものではない。

## 判定

`experiment-continue`

- スキーマ分離、QID任意化、保留キュー、保守的重複判定は成立した。
- 3万件のSQLite検索性能は目標の500 msを大幅に下回った。
- 3万件の高信頼レコードを供給できる再利用可能な収集元はまだ確認できていない。
- 次のゲートは全面実装ではなく、公的データの供給量・権利条件・抽出誤り率の実測とする。
