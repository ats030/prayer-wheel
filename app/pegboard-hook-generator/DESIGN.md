# DESIGN.md

このアプリは **購入者の手元で動く売り物** である。社内ツールと違い、初見の人が
説明なしで触れることと、オフラインで完結することが最優先される。

視覚テーマは他の自作アプリ (rss-reader, writing) と同じ Linear 系のダークUIを
踏襲する。ただし本アプリは 3Dプレビューが主役なので、コントロールは左に寄せ、
キャンバスに視線が行くようにする。

## Typography

- システムサンス (Inter → SF Pro → Segoe UI → Helvetica → Arial)。
- 本文 14px、メタ情報 12-13px。装飾的なディスプレイ書体は使わない。
- 寸法の数値は `tabular-nums` にして、スライダー操作中に桁がずれないようにする。

## Components

- ボタン: radius 6px、細い枠。主要ボタンのみ purple。
- 数値入力はスライダーと数値欄を横に並べる。スライダーだけだと正確な寸法を
  指定できず、数値欄だけだと形状の当たりがつかないため両方出す。
- 適合判定は success / warning / danger の3状態を色とテキストの両方で示す
  (色だけに情報を持たせない)。

## Layout

- 2カラム。左 = パラメータ (固定幅 320px)、右 = プレビューと寸法。
- 900px 以下で1カラムに落とし、プレビューを先頭に置く。
- 余白は 8 / 12 / 16 / 24 / 32px。影ではなく境界線で領域を分ける。

## Interaction

- パラメータ変更は即座にプレビューへ反映する (再生成ボタンを挟まない)。
- プレビューはドラッグで回転、ホイールで拡大縮小。
- 穴に入らない寸法になったら STL ボタンを止めるのではなく、警告を出したうえで
  ダウンロードは許す。板厚や穴径が規格外の有孔ボードもあるため。

## Do

- オフラインで完結させる。外部CDN・フォント・スクリプトを一切参照しない
  (購入者はzipを解凍してローカルで開く)。
- 生成される寸法を常に数値で見せる。買った人が印刷前に検算できること。

## Don't

- ライブラリを足さない。three.js等を入れると配布サイズと信頼性を損なう。
- ランディングページ的なセクション、グラデーション、大きな角丸を作らない。
