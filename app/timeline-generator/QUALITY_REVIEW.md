# 生成年表の品質評価

評価日: 2026-10-02。評価issue: ats030-0jkw1。改善追跡issue: ats030-3fxm4。

## 結論

出典をたどれる短い読み物としては使えますが、「主要な出来事から歴史の全体像を読む」という目的には要改善です。
年代の取り違え、テーマの拡張、重要な出来事の欠落、出典間の食い違いの未提示が残っています。
文章の読みやすさより、年代と出来事の結び付けと網羅性を優先して改善すべきです。

## 対象と方法

保存済みID 1〜4の結果を読み取りました。新たな生成・再生成やアプリの修正は行っていません。
インターネット6件、Claude Code 2件、コーヒー10件、ラーメン6件、計24項目です。
使用された出典ページ7件を再取得し、同じ正規化を使って引用の実在を確認しました。24/24項目で一致しました。
これは引用実在率であり、史実の正答率ではありません。生成時の全文は保存されていないため、比較対象は評価時のページです。
主要な出来事と疑わしい箇所を公式発表・当事者資料・自治体資料と照合しました。全24項目を独立した歴史研究資料で検証し尽くした評価ではありません。

以下の判定は編集上の判断です。件数の少なさだけでは不合格にせず、重要な転換点・テーマ適合・年代の正しさで判断しました。

| 年表 | 件数／出典ページ数 | 判定 | 主な理由 |
|---|---:|---|---|
| インターネット 1980年以降 | 6／2 | 要修正 | Twitter日本語版の年が誤り。WWWの誕生など主要項目がなく、2007年で終わる |
| Claude Code | 2／2 | 不十分 | 1件が関連モデルの出来事。Code本体の一般公開がない |
| コーヒー | 10／2 | 要補強 | 伝承と史料の区別に課題。1888年で終わり、近現代がない |
| ラーメン | 6／1 | 要補強 | 専門施設の出典を追えるが、出典にある重要な転換点を落としている |

## 重要な指摘

### 1. 2006年のSNS項目は、別々の年の出来事を混ぜている

保存結果はFacebookの一般向け展開とTwitter日本語版開始を2006年の一項目にまとめています。
[引用元のデジタルアーツ年表](https://www.daj.jp/history/internet/)では、この段落は2008年の項目に属します。段落内の2004・2006年はサービスの背景です。
[Twitterの公式発表](https://blog.x.com/en_us/a/2008/twitter-for-japan)は2008年4月22日、日本語の[開発ブログ](https://twitterjp.blogspot.com/2008/04/twitter.html)は日本時間4月23日の開始を記載しています。日付の時差とは別に、年表の2006年は誤りです。

実装のArticleParserで出典を再解析すると、4文字の「2008」見出しは残らず、背景の2006年を含む段落だけが残りました。
flush()が8文字未満の行を除外し、本文も年代を含む行に絞っているためです。年が本文中に存在することを確かめても、どの出来事の年かは検証できません。
生成時の中間入力・判定ログは保存されていないので、生成時にモデルがどの過程で誤認したかまでは断定しません。

1983年の項目も、[Internet Societyの説明](https://www.internetsociety.org/news/press-releases/2013/new-years-day-marks-30th-anniversary-of-major-milestone-for-global-internet/)に沿って「ARPANETがTCP/IPへ移行」と書く方が、単なる「標準化」より出来事を正確に表せます。
網羅性の面では、[CERNが説明する1989年のWWW誕生、1993年の公開](https://home.cern/science/computing/the-birth-of-the-web/where-web-was-born/)は有力な追加候補です。

### 2. Claude Code本体と、Claudeモデルの出来事が混ざっている

プレビュー公開は[Anthropicの2025年2月24日発表](https://www.anthropic.com/news/claude-3-7-sonnet)と整合します。
一方、「推論モードの提供開始」はClaude 3.7 Sonnetの出来事です。背景としては関連しますが、Claude Codeの更新と同じ扱いにすると対象がぼやけます。
[2025年5月22日の公式発表](https://www.anthropic.com/news/claude-4)にはClaude Codeの一般公開、IDE連携、SDKなどがあり、保存年表には一般公開さえありません。
現在の2項目はいずれも「2025年」表示です。短期間で変わる製品では、出典にある月日も残すと経過が分かりやすくなります。

### 3. コーヒーは伝承と史料の食い違いを表示する必要がある

1683年のウィーン初のコーヒーハウスは引用元に記載されていますが、[ウィーン市の資料](https://presse.wien.gv.at/presse/2011/11/11/wiener-kaffeehauskultur-ist-immaterielles-kulturerbe-der-unesco)は、1683年のコルシツキーの話に証拠がなく、史料で確認できる最初の店をディオダートによる1685年と説明します。
保存結果の「とされています」だけでは、伝承と確認された記録の違いは読み取れません。引用元に書かれているという理由だけで史実として採用することに限界があります。
900年の記録なども、引用元の留保を保つ必要があり、この監査では独立した原史料まで確認していません。

10件のうち3件が都市のコーヒーハウス開業で、最新は1888年です。「歴史と普及」というテーマなら、近現代の製造・流通・飲用文化を含める余地があります。
例えば[1938年のネスカフェ発売](https://www.nestle.co.uk/en-gb/media/newsfeatures/nescafe-75-years)、[1969年のUCCミルク入り缶コーヒー発売](https://www.ucc.co.jp/company/pressroom/pickup/20250716.html)などです。どれを採用するかは編集判断ですが、10件あるだけで全体像を満たしたとは言えません。

### 4. ラーメンは、出典にある主要項目を落としている

6項目とも[新横浜ラーメン博物館の年表](https://www.raumen.co.jp/rapedia/study_history/)に引用が存在しました。ただし、全件が同じページなので出典間の照合はできていません。
同ページには1937年の南京千両、1947年の久留米「三九」の白濁豚骨スープ、1958年のチキンラーメン発売もありますが、保存結果にはありません。
1958年の発売は[日清食品の公式資料](https://www.nissin.com/jp/company/news/4446/)でも確認できます。「多様な展開」を説明する上で、1989年のブームだけよりも、その前段の技術や商品を含める方が有用です。

## 実装で確認できたことと、未確認のこと

- 年代だけの短い見出しが欠落することを、実ページと現行パーサーで再現しました。
- 本文は1ページあたり先頭3000文字に制限されています。ラーメン資料では2005年の項目が約2952文字目にあり、2007年以降の項目は境界の後でした。近年の情報を落とす構造的な偏りがあります。
- 生成プロンプトは10件を求め、検証後に不足を補う処理はありません。資料中にあった項目が候補生成と検証のどちらで落ちたかは、保存結果だけでは分かりません。
- 照合用入力は出来事と引用で、見出しを含む周辺文脈や独立資料は渡されません。同じモデルによる引用一致の判定を独立した史実確認とみなすことはできません。
- 文章は短く年代順で、出典・引用にアクセスできます。一方、タイトルの「トルコでの開業」「オックスフォードの拠点」は、対象を「コーヒーハウス」と明示すると読みやすくなります。

## 改善の優先順

1. 見出しと段落を一緒に扱い、年と出来事の対応、伝承・推定・史料間の食い違いを検査する。
2. 入力テーマの範囲を保ち、公式・当事者資料を優先する。関連モデルなど背景情報は本体の出来事と区別する。
3. 時代別に候補を集め、主要転換点の欠落を確認する。少ない場合も件数合わせで推測しない。

生成機構の改善後も、現在保存されている結果は自動では変わりません。改善実装時には再生成と既存結果の扱いを別途決める必要があります。
