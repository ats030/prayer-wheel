# Species Explorer

植物・動物の写真を最大3枚と任意の撮影地域・日付・大きさから、ローカルVLMまたは登録したOpenAI・Anthropic・Gemini APIで観察し、識別候補を最大3件表示する実証版です。 厳格回答モードで候補学名をiNaturalistの分類データへ自動照合し、完全一致しない名前は表示しません。VLMだけの候補は写真との一致を未検証と明示し、生成された特徴文は表示しません。候補は和名を主表示し、日本語名が分類データにない場合は「和名未登録」と明示します。 Pl@ntNet APIキーを登録すると、明示的に選択した植物写真だけを植物専用識別と比較できます。
画像はメモリ上で縮小・再エンコードしてEXIFを除去し、保存しません。
設定画面でAmazon書籍検索用の特別リンクテンプレートを登録すると、各候補の和名から「和名＋図鑑＋本」を書籍カテゴリで検索する広告リンクを表示できます。Amazon Creators APIのCredential ID、Secret、Partner Tagも登録すると、該当する書籍が見つかった候補ではAPIが返した商品ページを優先し、見つからない場合やAPI障害時は検索リンクへ戻します。認証情報は画面へ再表示しません。広告は識別候補・順位に影響せず、利用者はブラウザ単位で非表示にでき、設定画面から解除できます。

```bash
cd /home/ats030
uv run uvicorn --app-dir /home/ats030/app/species-explorer main:app --host 0.0.0.0 --port 8523
```

計算資源、APIキー、使用モデルは画面上部の「設定」から変更できます。ローカルモデルはOllamaにインストール済みで画像入力に対応するものを自動表示します。APIキーは `~/.config/species-explorer/settings.json` に権限 `0600` で保存し、画面には再表示しません。

```bash
uv run --with pytest pytest -q
```

識別結果は観察の補助であり、食用・毒性・安全性の判断には使用できません。
