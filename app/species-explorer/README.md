# Species Explorer

植物・動物の写真を最大3枚と任意の撮影地域・日付・大きさから、ローカルVLMまたは登録したOpenAI・Anthropic・Gemini APIで観察し、識別候補を最大3件表示する実証版です。 厳格回答モードで候補学名をiNaturalistの分類データへ自動照合します。写真上の観察点が2件未満、類似種との識別点がない、または矛盾がある候補も削除せず、「確証なし」と不足理由を表示します。分類データで完全一致しない名前だけは表示しません。観察点はAI抽出で未検証と明示します。候補は和名を主表示し、日本語名が分類データにない場合は「和名未登録」と明示します。 Pl@ntNet APIキーを登録すると、明示的に選択した植物写真だけを植物専用識別と比較できます。Geminiでは写真上の特徴を先に観察し、類似種との識別点と矛盾を比較してから、構造化された候補を返します。
画像はメモリ上で縮小・再エンコードしてEXIFを除去し、保存しません。
「現在地を取得」は利用者が押したときだけブラウザのGPS許可を求め、位置はページ内メモリだけで扱い、識別APIや保存先へ送りません。採取の許可や食用可能性は断定せず、未確認条件と環境省・厚生労働省の確認先を表示します。
写真にEXIFの撮影日時やGPSが含まれる場合は、写真選択時にサーバー内で読み取り、撮影日と約11m単位に丸めた座標を入力欄へ提案します。内容は識別前に確認・修正でき、識別時には撮影情報として選択中のAIへ送られます。画像本体は再エンコードしてEXIFを除去し、保存しません。
判定履歴は最大50件をブラウザのIndexedDBだけに保存します。結果、確認済み撮影情報、丸め済み座標、最大320pxのJPEGサムネイルを含み、サーバーへ同期しません。個別・全削除が可能です。位置付き履歴は利用者が「地図を表示」を押した場合だけ、丸め済み座標をOpenStreetMapへ送って表示します。
動物候補では、写真に種特異的な性的二型の根拠が見える場合だけオス・メスを推定し、それ以外は「判別不能」と表示します。分類群に応じてAnimal Diversity Web、Cornell All About Birds、FishBase、AmphibiaWeb、Reptile Database、GBIFのいずれかへ照合リンクを表示します。外部サイトの内容は自動取得しません。
設定画面でAmazon全商品検索用の特別リンクテンプレートを登録すると、識別候補の和名と識別カテゴリから関連商品を全カテゴリで検索する広告リンクを表示できます。Amazon Creators APIのCredential ID、Secret、Partner Tagも登録すると、巡回選択された候補に商品が見つかった場合はAPIが返した商品を画像付きカードで最大4件表示し、見つからない場合やAPI障害時は検索リンクへ戻します。認証情報は画面へ再表示しません。広告は識別候補・順位に影響せず、広告設定が有効な場合は結果ページに常時表示します。

```bash
cd /home/ats030
uv run uvicorn --app-dir /home/ats030/app/species-explorer main:app --host 0.0.0.0 --port 8523
```

計算資源、APIキー、使用モデルは画面上部の「設定」から変更できます。ローカルモデルはOllamaにインストール済みで画像入力に対応するものを自動表示します。APIキーは `~/.config/species-explorer/settings.json` に権限 `0600` で保存し、画面には再表示しません。

```bash
uv run --with pytest pytest -q
```

識別結果は観察の補助であり、食用・毒性・安全性の判断には使用できません。
