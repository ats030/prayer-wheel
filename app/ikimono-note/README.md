# 生きものノート (ikimono-note)

表示名は「生きものノート」。URL・ディレクトリ名・端末内の記録キー (`species-history` など) は `ikimono-note` のまま据え置く。
変えると既存の端末内の記録が読めなくなるため。

種の決め手が不足する場合も、写真・地域・季節から合理的に絞れる同属種を最大3件まで「確証なし」の種候補として示します。候補学名は分類データで実在確認し、合理的な種候補を作れない場合だけ属・科候補へフォールバックします。結果と履歴には「種候補・属候補・科候補」の分類階級を表示します。

植物・動物の写真を最大3枚と任意の撮影地域・日付・大きさから、ローカルVLMまたは登録したOpenAI・Anthropic・Gemini APIで観察し、識別候補を最大3件表示する実証版です。 厳格回答モードで候補学名をiNaturalistの分類データへ自動照合します。写真上の観察点が2件未満、類似種との識別点がない、または矛盾がある候補も削除せず、「確証なし」と不足理由を表示します。分類データで完全一致しない名前だけは表示しません。観察点はAI抽出で未検証と明示します。候補は和名を主表示し、日本語名が分類データにない場合は「和名未登録」と明示します。 Pl@ntNet APIキーを登録すると、明示的に選択した植物写真だけを植物専用識別と比較できます。Geminiでは写真上の特徴を先に観察し、類似種との識別点と矛盾を比較してから、構造化された候補を返します。
画像はメモリ上で縮小・再エンコードしてEXIFを除去し、保存しません。
画像を選択するとブラウザの現在地取得を試みます。拒否・タイムアウト時も写真判定は続行でき、「現在地を再取得」から再試行できます。現在地は識別AIへ送らず、判定後に約11m単位へ丸めてブラウザ内履歴へ保存します。写真にEXIF位置がある場合は撮影地点として現在地より優先します。採取の許可や食用可能性は断定せず、未確認条件と環境省・厚生労働省の確認先を表示します。
写真にEXIFの撮影日時やGPSが含まれる場合は、写真選択時にサーバー内で読み取り、撮影日と約11m単位に丸めた座標を入力欄へ提案します。内容は識別前に確認・修正でき、識別時には撮影情報として選択中のAIへ送られます。画像本体は再エンコードしてEXIFを除去し、保存しません。
記録の保存先は Google ドライブひとつです。ログインに Google アカウントを使う以上、全員が
持っている置き場はここなので、選ばせていません。以前は WebDAV・端末内のフォルダ・ファイル
書き出しも並べており、保存先の欄だけでボタンが7個並ぶ画面になっていました。

記録が増減するたび自動で書き直します。記録するたびに許可を求められては使い物にならないため、
一度つないだ相手には `prompt: "none"` で黙って取り直します。取れなければ何もしません
(記録は端末の中に残り、設定画面でつなぎ直せます)。ブラウザが覚えるのは「一度つないだ」
という事実とファイルのIDだけで、トークンは保存しません。

書けたかどうかは記録ページの先頭に出します。黙って失敗し続けると、記録が残っていると
思い込んだまま端末を変えて、全部消えたことに後で気づくためです。一度もつないでいない場合も
「この端末の中だけにあります」と伝えます。

APIキーの入力欄は、ブラウザのパスワード管理に預けられる形にしてあります
(`autocomplete="current-password"` と、どのサービスの鍵かを示す username 相当の欄)。
以前は `autocomplete="new-password"` で、ブラウザが保存を提案しませんでした。預け先は
ブラウザ (または Google アカウント) で、本サービスは受け取りません。暗号化も同期も
ブラウザに任せられます。

APIキーは含めません。ファイルが漏れたとき、そのまま課金されるキーが渡るためです。
入れ直しの手間は、ブラウザのパスワード管理に預けることで解いています。同じものを
二重に持つと、片方が漏れる筋が増えます。

読み込みは既存の記録と混ぜます。片方の端末で消した記録はもう片方に残ります (消したことを
伝える印を持たないため)。APIキーは含めません。写真は data URL として同じファイルに収める
ため、記録50件でおおむね数MBになります。

Google ドライブは WebDAV を提供していないため、OAuth と Drive API を使います。
通信はブラウザから Google へ直接行き、本サービスのサーバーを経由しません
(写真もトークンも運営者を通りません)。権限は drive.file に絞ってあり、この
アプリが作った ikimono-note.json しか見えません。

使うには運営者が Google Cloud Console で OAuth クライアントID (ウェブアプリ
ケーション) を作り、環境変数で渡します。クライアントIDは公開情報で、秘密鍵は
使いません。

```bash
IKIMONO_GOOGLE_CLIENT_ID=xxxxx.apps.googleusercontent.com
```

承認済みの JavaScript 生成元には、実際に開くURLをすべて登録します。

- `https://ubuntu-server-app.tailf74832.ts.net` (公開版)
- `https://ubuntu-server-app.tailf74832.ts.net:8443` (運営者用)

未設定のときは画面にその旨を出し、接続ボタンは出しません。

地図の下敷きは4つから選べます (地図・地形・起伏・写真)。どこで見つけたかを思い出すには、
道より地形が要ることがあるためです。地形・起伏・写真は国土地理院のタイルで、出典を示せば
自由に使えます (政府標準利用規約)。日本の外は写らないので、既定は OpenStreetMap のままです。

判定履歴は最大50件をブラウザのIndexedDBだけに保存します。長辺最大960pxのJPEG画像、判定要約、使用モデル、撮影情報、丸め済み座標、各候補の確信度・観察点・識別点・矛盾・不足理由・追加確認点・雌雄推定根拠を含み、サーバーへ同期しません。履歴画像はクリックして拡大でき、個別・全削除が可能です。位置付き履歴は利用者が「地図を表示」を押した場合だけ、丸め済み座標をOpenStreetMapへ送って表示します。旧形式の履歴は存在する項目だけを表示します。
候補の学名が種の保存法の規制対象と完全一致した場合だけ、「種の保存法の国内希少野生動植物種です」と事実を表示し、環境省の一覧へ誘導します。リスト (国内希少野生動植物種458件 + 緊急指定種3件) は `data/protected_species.json` として同梱し、実行時に env.go.jp を叩きません。規制の内容は指定の種類で違う (特定第二種は販売・頒布目的の捕獲等だけが規制) ため、法律の中身は要約せず、指定の種類だけを添えます。一致しなかった候補には何も表示しません。無印は「指定なし」ではなく、亜種で指定されている種は種名では当たらず、都道府県の条例は独自に指定しているためです。更新は `uv run --with openpyxl python data/build_protected_species.py` で作り直します。座標から採取規制を判定しない理由は `docs/tool-license-collection-regulation-data.yaml` にあります。
動物候補では、写真に種特異的な性的二型の根拠が見える場合だけオス・メスを推定し、それ以外は「判別不能」と表示します。分類群に応じてAnimal Diversity Web、Cornell All About Birds、FishBase、AmphibiaWeb、Reptile Database、GBIFのいずれかへ照合リンクを表示します。外部サイトの内容は自動取得しません。
設定画面でAmazon全商品検索用の特別リンクテンプレートを登録すると、識別候補の和名と識別カテゴリから関連商品を全カテゴリで検索する広告リンクを表示できます。Amazon Creators APIのCredential ID、Secret、Partner Tagも登録すると、APIが返した商品を画像付きカードで最大4件表示し、見つからない場合やAPI障害時は検索リンクへ戻します。棚は候補ごとにその候補のブロックの中へ置き、ラベルに候補名を入れます (「広告 · Amazonで◯◯の関連商品」)。以前は全候補のあとに棚が1つあるだけで、どの候補の広告かは並び順の暗黙知でした。そのぶん決め手のない候補にも広告が付くので、候補名を出す約束は外せません。識別1回あたりの商品API呼び出しは通しで6回・1棚2回までとし、上の候補から順に埋めます (棚ごとの上限がないと最初の候補が切り口を使い切り、3番目が1回も引けません)。集めた商品は棚をまたいで覚え、どの候補でも当たる「分類+図鑑」が3つ並ばないようにします。商品の検索語の組み立てと食品の除外は `static/assets/products.js` に置き、2画面で共有します。認証情報は画面へ再表示しません。広告は識別候補・順位に影響せず、広告設定が有効な場合は結果ページに常時表示します。

商品APIは Amazon 側の口座の状態で止まります。実際に `403 AssociateNotEligible`（適格販売が足りない。2025年11月以降は直近30日で10件必要）で止まっており、認証情報を入れ直しても直りません。条件を満たすと2日ほどで自動的に戻ります。止まっている間、画面は検索リンクのフォールバックへ静かに戻ります。断られた理由と運営者がとれる手は journal（`journalctl --user -u ikimono-note -g Amazon商品API`）と、設定画面の「関連商品の広告」に出します。設定画面の「認証情報を登録済み」は登録の有無しか示さないので、その下に最後の呼び出し結果を別に置いています（一度も呼んでいないうちは何も出しません。推測で「正常」と書くと同じ思い込みを作るため）。この状態は運営者用にだけ返し、公開版の訪問者へは渡しません。
判定履歴の詳細にも写真付きの商品カードを最大4件表示します。「調べた内容を見る」を開いたときに初めて商品APIを呼ぶため、一覧を表示するだけでは1件もリクエストしません。検索はその種に固有の切り口 (候補名の書籍 / 候補名+観察 / 候補名+育て方・飼育 / 学名の書籍) を毎回ランダムな順で試し、集まった商品を合成します。「分類+図鑑」のような一般書は必ずヒットして枠を占めるため、最後の保険として最大2件までに制限します。同一題名の重複は除き、食用を連想させる語 (茶・食用・乾燥・サプリなど) を含む商品は除外します。安全カードで「食べられるかは判定しません」と表示している以上、誤同定のときに食品広告が後押しになってはいけないためです。語による除外なので完全ではありません。

2つのプロセスを別の役割で動かします。設定ファイルは共有するため、運営者用での
変更は公開版にも効きます。

| | ポート | 待受 | モード | 役割 |
|---|---|---|---|---|
| 運営者用 `ikimono-note.service` | 8523 | `0.0.0.0` (Tailscale・LAN) | 非公開 | 設定の保存、動作確認 |
| 公開版 `ikimono-note-public.service` | 8524 | `127.0.0.1` のみ | 公開 | Tailscale Funnel の向け先 |

8523 と 8524 は、ブラウザから見ると別サイトです (ポートが違うため)。localStorage も
sessionStorage も分かれるので、行き来すると設定が消えたように見えます。避けようが
ないので、運営者用の画面には「この画面は運営者用」と出し、公開版へのリンクを置いて
あります。利用者と同じ動きを確かめたいときは公開版で見てください。

そもそも設定の持ち方が違います。運営者用はサーバー (settings.json) に保存し、公開版は
利用者のブラウザに置きます。同じものを二度設定する必要はありません。

Funnel は 8524 へ向けます。8523 は認証がなく設定を書き換えられるので、
Funnel やポート開放の対象にしないでください。

運営者用は Tailscale 内限定の HTTPS も張ってあります。

```bash
tailscale serve --bg --https=8443 8523   # tailnet only。Funnel ではない
tailscale serve --https=8443 off         # やめるとき
```

`https://ubuntu-server-app.tailf74832.ts.net:8443/` で開きます。

```bash
systemctl --user restart ikimono-note ikimono-note-public
/home/ats030/app/ikimono-note.sh          # 運営者用を手で起動する場合
/home/ats030/app/ikimono-note-public.sh   # 公開版を手で起動する場合
```

使うAI、APIキー、モデルは画面上部の「設定」から変更できます。OllamaではURLを入力でき、その接続先にインストール済みで画像入力に対応するモデルを自動表示します。別端末のOllamaを使う場合は、Ollama側でこのサーバーからの接続を許可してください。接続先とAPIキーは `~/.config/ikimono-note/settings.json` に権限 `0600` で保存し、APIキーは画面へ再表示しません。

```bash
uv run --with pytest pytest -q                                    # 208件
uv run --with playwright python tests/smoke_browser.py            # 実ブラウザで主要導線
uv run --with playwright python tests/smoke_browser.py --identify # 識別まで通す
```

pytest は速いものの、文字列を検査しているだけなので画面が動くかは分かりません。実際に、撮影画面が丸ごと動かない状態と、APIキーが保存できない状態を、全テストが緑のまま配ったことがあります (どちらも今は検査項目を足してあります)。`smoke_browser.py` は実ブラウザで5ページを開き、共通スクリプトの読み込み、保存先の選択、テーマの切り替え、結果の描画、撮り足し (写真が置き換わらず増えるか)、JSエラーの有無を見ます。`--identify` を付けると、写真を選ぶところから識別・記録・調べ直しまで通します (Ollama で1分ほど)。

役目は、まだ検査項目を書いていない壊れ方を捕まえることです。壊し方を2通り試したときはどちらも pytest 側も拾ったので、置き換えではなく網を重ねるものと考えてください。

## 写真の質を見てから送る

暗すぎる・小さすぎる・ぼけている写真をAIへ送っても、返るのは自信のない推測か、もっともらしい
誤りです。送る前に見て、撮り直しを促します。

| | 弾く | 注意して続ける |
|---|---|---|
| 短辺 | 200未満 | 300未満 |
| 明るさ | 15未満 | 25未満 |
| 輪郭の強さ | — | 50未満 |
| 明暗の幅 | — | 10未満 |

閾値は評価用の写真44枚 (iNaturalist research-grade) の分布から決めました。その最小値は
sharpness 161.4 / brightness 35.7 / contrast 15.2 で、閾値はいずれもその下にあります。
実際に44枚を通したところ、**弾いたもの0件、注意を出したもの1件 (2.3%)** です。

弾くのは何が写っているか分からない場合だけにしています。迷う程度で止めると、条件の悪い
場所でしか会えない生きものを調べられなくなるためです。

縮小すると輪郭が相対的に強まり、ぼけの指標は逆に上がります (160x120 で 4899、元は 2841)。
小さい写真はぼけ判定をすり抜けるので、先に大きさを見て、小さいものにぼけの判定を下しません。

識別結果は観察の補助であり、食用・毒性・安全性の判断には使用できません。

## Google の認可とポップアップ

ドライブへの接続は、Google の認可画面をポップアップで開き、許可を得たあと親ウィンドウへ
`postMessage` で結果を返す。このため `Cross-Origin-Opener-Policy` を `same-origin` に
すると動かない。`window.opener` が切れて結果が届かず、**認可は成功しているのに
「ポップアップが閉じられた」(popup_closed) としか見えない**。

```
Cross-Origin-Opener-Policy: same-origin-allow-popups
```

`allow-popups` は、自分が開いたポップアップとのやり取りだけを許す。別サイトから
開かれたときにこちらを覗かれない保護は残る。

症状が Console 側の設定不足と見分けられないため、原因の特定に時間がかかった。
スコープ・テストユーザー・JavaScript 生成元をすべて正しく設定しても変わらないときは、
このヘッダーを疑うこと。

## ログイン

公開版 (8524) ではログインを必須にしています。Google アカウントでログインし、
パスワードは受け取りません。自分で預かると、ハッシュの選定・リセット導線・漏洩時の
対応まで抱えることになり、個人で運用するには重すぎるためです。

サーバーが保存するのは**識別子とメールアドレス、登録日時、最終利用日時だけ**です。
写真・記録・設定・APIキーは、これまでどおり利用者の側に残ります。ログインしても
預かるものは増えません。設定画面の「退会する」で削除できます。

```bash
IKIMONO_GOOGLE_CLIENT_ID=xxxxx.apps.googleusercontent.com
IKIMONO_GOOGLE_CLIENT_SECRET=xxxxx          # ログインに必要 (ドライブ連携では不要)
IKIMONO_PUBLIC_ORIGIN=https://ubuntu-server-app.tailf74832.ts.net
IKIMONO_SESSION_SECRET=<64桁の16進>          # 省略時は起動ごとに変わる (再起動で全員ログアウト)
```

Google Cloud Console の「承認済みのリダイレクト URI」に
`<PUBLIC_ORIGIN>/auth/callback` を登録します (ドライブ連携で使う「承認済みの
JavaScript 生成元」とは別の欄です)。

**未設定のときはログインを求めません。** 設定を入れる前に必須にすると、運営者を
含めて誰も入れないアプリになるためです。運営者用 (8523) は tailnet の中だけなので、
こちらでも求めません。二重にすると、設定の不備で自分が締め出されます。

利用者の情報は `~/data/ikimono-note/users.db` (0600) に置きます。消えると
戻らないため `backup-data.timer` の対象です。

## 一般公開モード

公開版は全年齢対象です。UIはライト基調で、既定では端末の設定（`prefers-color-scheme`）
に従います。ヘッダーのボタンで「自動 → ライト → ダーク」を切り替えられ、選択は
`localStorage`（キー `species-theme`）へ保存されて全ページとリロードに引き継がれます。
「自動」を選ぶと保存を消して端末の設定へ戻ります。画面の言葉は小学校高学年が読める水準に
そろえ（「識別候補」→「似ている生きもの」など）、安全上の警告は
「食べられるか」「さわってよいか」「持ち帰ってよいか」の3点に分けて常時表示します。
利用規約に対象年齢と保護者の監督、プライバシーポリシーにお子さまの利用を明記し、
APIキーの登録と料金負担は契約者本人が行う旨を設定画面にも表示します。

一般公開では、利用者のAPIキーをサーバー設定へ保存しません。キーはブラウザの
`sessionStorage` にだけ保持され、判定リクエスト時にHTTPS経由で送信されます。
タブを閉じると消えます。プロバイダーとモデルの選択だけは `localStorage` に残ります。

```bash
IKIMONO_PUBLIC_MODE=1
IKIMONO_ALLOWED_HOSTS=species.example.com
IKIMONO_PUBLIC_LOCAL=0
IKIMONO_PUBLIC_AFFILIATE=1
```

- `IKIMONO_PUBLIC_MODE=1`: 共有設定の更新を403で拒否し、BYOK公開モードを有効化
- `IKIMONO_ALLOWED_HOSTS`: 公開ドメインをカンマ区切りで指定
- `IKIMONO_PUBLIC_LOCAL=1`: 運営者のOllamaを公開する場合だけ明示的に有効化
- `IKIMONO_PUBLIC_AFFILIATE=1`: 公開版でも広告を出す。値は `~/.env` に置く

この環境変数は運営者設定より手前のゲートです。`0` だと `/api/settings` の広告設定ごと空になり、
候補ごとの検索リンクの棚すら描かれません (`/api/amazon/products` も404)。運営者用 (8523) の

公開はTailscale Funnel (TLS終端) 経由で8524番ポートへ流します。8523番ポートは
運営者用でインターネットへ出しません。自前のリバースプロキシを使う場合も同様に、
公開側だけを前段へつなぎます。プロキシ側でもリクエストサイズ制限とレート制限を設定し、
`/health` 以外をHTTPSへ強制します。アプリ内のIPレート制限は単一プロセス向けの初期防御であり、
複数ワーカー・複数台構成では共有レートリミッターへ置き換える必要があります。

公開モードの安全境界:

- `POST /api/settings` は無効
- 任意のOllama URLは受け付けない
- 外部AIのモデルはサーバーの許可リストからのみ選択
- 判定はIPごとに1分6回、メタデータ読取は1分20回
- APIキーはレスポンス、サーバー設定、判定履歴へ含めない
- Hostヘッダー、フレーム埋込み、MIME sniffing、カメラ・位置情報権限を制限
- `/docs`・`/redoc`・`/openapi.json` を閉じる
- Content-Security-Policy を `'unsafe-inline'` なしで適用。CSSとJSは
  `/assets` と `/theme.js` からのみ読み、外部に許すのは利用者が押して初めて出る
  地図タイル (`tile.openstreetmap.org`) と広告の商品画像 (Amazon) だけ。
  ページにインライン `<style>`／`<script>`／`style` 属性を足すとCSPに弾かれる
  （テストで検出する）

Tailscale Funnelでの公開と停止:

```bash
tailscale funnel --bg 8524   # 公開版へ向ける。8523 (運営者用) を指定しないこと
tailscale funnel status
tailscale funnel reset
```

初回はTailscale管理画面でFunnelの所有者承認が必要です。`reset` はこの端末の
Funnel設定を削除するロールバック操作です。公開前にプライバシーポリシーの
問い合わせ窓口が実在し、外部から到達できることを確認してください。
