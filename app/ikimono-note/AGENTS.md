# ikimono-note の作業指示

親ディレクトリの `AGENTS.md` に加えて、このアプリでは次のルールを守る。

## 更新履歴は公開作業の完了条件

- 利用者に見える機能追加・動作変更・不具合修正は、同じ作業で `static/changelog.html` に記載する。記載を後回しの別作業にしない。
- 画面の見え方や動きが変わらない内部整理だけの変更は記載不要。
- 実際に公開する日を日本時間で記載する。最終更新日も合わせ、新しい日付を上に置く。同日の変更は同じ節にまとめる。
- 利用者に何が変わったか、どう使うかを簡潔に書く。必要なら制約や確認操作も添え、未公開の機能を公開済みとして記載しない。
- コミット前に、利用者向け変更と更新履歴の記載が対応しているか確認する。記載対象外と判断した場合は、その理由を作業issueに残す。
- 公開時は更新履歴も同時に反映し、公開URLの `/changelog` で追記内容と日付を確認する。コードのpushだけでは公開作業を完了にしない。
