山から器へ、器から町へ

01 / 原料

泉山磁石場

白い器の出発点は、石でした。泉山は有田の磁器づくりを支えた陶石の採掘場です。削られた山の姿から、原料を取り出す仕事の大きさを想像できます。

有田町泉山1-33。採掘坑の内部には入れません。

出典：有田観光協会・泉山磁石場

02 / 焼成

天狗谷窯跡

原料があっても、器はまだできません。天狗谷には、17世紀に磁器を焼いていた登り窯の跡が残ります。発掘では複数の窯と、焼き損じた器を捨てた場所が見つかっています。

有田町白川一丁目1804番地4ほか。位置は有田町の施設地図に基づきます。

出典：有田町・天狗谷窯跡の解説 / 施設・位置の案内

03 / 町並み

トンバイ塀のある裏通り

焼く仕事は、町の景色にも残りました。トンバイ塀には、使い終えた耐火レンガや窯道具が使われています。塀を眺めるとき、その材料が窯で働いていたことにも目を向けてみてください。

泉山から大樽にかけての裏通りに分布。地図の点は上幸平の代表地点です。

出典：有田観光協会・トンバイ塀

04 / 信仰

陶山神社

磁器は食卓を離れ、鳥居にもなりました。陶山神社には有田焼の鳥居や狛犬が並びます。境内の李参平碑からは、やきものの町が陶祖を記憶してきたことも読み取れます。

有田町大樽2-5-1。入口の踏切には遮断機がありません。警報中は踏切に入らず、白線の外で待ってください。

出典：有田観光協会・陶山神社と参拝案内

05 / 仕事の記録

有田陶磁美術館

採石や成形の仕事を、一枚の大皿に描いた資料があります。美術館が紹介する「染付有田皿山職人尽し絵図大皿」です。かつての焼き物倉庫を使った建物も、町の仕事の記憶を伝えています。

有田町大樽1-4-2。開館日と展示の状況は公式案内で確認できます。

出典：有田観光協会・大皿の解説 / 有田町・美術館の案内

場所を結ぶ理由

つながりを選んで、もう一歩

  • 石を掘る場所から、器を焼く場所へ

    泉山は原料を採る場所、天狗谷は初期の磁器を焼いた場所。文化庁は、原料供給地と窯跡を「肥前磁器窯跡」としてまとめて紹介しています。磁器づくりの二つの段階を、地図で見比べられます。

    出典：文化庁・肥前磁器窯跡

    原料と窯のつながりを見る →

  • 窯の仕事を、裏通りの塀で読む

    トンバイ塀の材料は、登り窯で使われた耐火レンガや窯道具。窯跡で焼成の仕事を知り、裏通りでその道具の再利用を見る、という視点で結んでいます。

    テーマで結ぶ関係：塀の材料が天狗谷窯から来たかどうかは未確認です。

    出典：有田観光協会・塀の材料 / 有田町・登り窯の解説

    窯と塀のつながりを見る →

  • 陶石の発見を、町はどう記憶した？

    泉山での陶石発見は、李参平らに結び付けて伝えられています。陶山神社には李参平の碑と有田焼の鳥居があり、やきものづくりの記憶と信仰が重なります。

    伝承を含む関係：発見者と創業の経緯は、観光協会の紹介に基づきます。

    出典：有田観光協会・陶石発見 / 陶山神社・李参平碑

    原料の山と神社を結ぶ →

  • 山の仕事は、大皿にも描かれている

    「染付有田皿山職人尽し絵図大皿」には、泉山での採石や原料の粉砕、器の成形が描かれています。実際の山と、器に残された仕事の記録を結ぶ関係です。

    出典：有田観光協会・大皿に描かれた工程

    採掘場と大皿の記録を結ぶ →

  • 道具の残る通りから、作品の残る蔵へ

    トンバイ塀が見られる裏通りは、有田陶磁美術館のある大樽まで続きます。町に残る道具と、元の焼き物倉庫に残る作品。二つの残り方から同じ産業を見られます。

    出典：有田観光協会・裏通りの分布 / 有田町・美術館の建物
