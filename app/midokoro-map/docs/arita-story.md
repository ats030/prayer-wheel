# 有田焼のつながりをたどる実験

Issue: ats030-b5jjy。資料確認日: 2026-10-07。

目的は、名前を知らない場所に文化的な関係から出会えることを集客の入口にする。
集客効果は未測定。全国版の関係グラフや自動推薦への拡張は今回の対象外。
公開時に検索へインデックスされることや、SNSの流入増を保証しない。

## 正本と編集

`frontend/stories/arita-porcelain.html` の5地点と5関係を正本とする。
地点の住所・座標、関係の種類、出典リンクはここを更新する。
JavaScriptは本文から地図と選択パネルを組み立て、別の説明データを持たない。
出典本文・写真・地図画像は転載せず、事実を独自の短い文章で紹介する。
テーマを選び、場所同士を見比べる構成は編集上の判断。事実の出典と区別する。
各URLのリンク先は第三者の著作物であり、リンク掲載をその著作物の商用再利用許可と解釈しない。

## 計測と判断

すべてのイベントはページ内で各1回、DNT時は0回。共有や操作を妨げない失敗許容の空POST。
サーバーは許可したイベント名のみ標準ログに出す。追加DB・Cookie・個人IDはない。
Sec-Fetch-Siteが他オリジンのリクエスト、本文付きPOST、未知イベント、クエリ付き計測パスは受理しない。
Cloud Runでは既存リクエストログ/visit-log集計、自己ホストではsystemd journalを使う。
プラットフォームが記録するIP等の既存HTTPメタデータを消去する変更は含まない。

| event | 意味 |
|---|---|
| view | JSが動作したページ読込 |
| entry-home | from=homeで読み込まれたページ |
| entry-shared | from=sharedで読み込まれたページ。新規ユーザー数ではない。 |
| explore | 初回の地点または関係の操作 |
| follow | 初回の関係の選択。現地周遊や2回以上の連続探索ではない。 |
| share-open | Web Share APIを初めて呼び出した操作 |
| share-returned | APIが成功応答した操作。相手への配信完了を証明しない。 |
| copy-success | クリップボードへの自動コピー成功。手動コピーは計測できない。 |

アクセスは自動リクエストで水増し可能で、ネットワーク制限等で欠測する。
同一ページの再読込は別カウント。個人を同定して重複排除しない。
イベント配送順は保証しない。集計期間の境界では単純な比率にずれが出る。

最初の100件のview到達後、explore/viewとfollow/viewを確認する。
暫定の判断基準としてexplore/view >= 30%、follow/view >= 20%を次テーマ検討の目安にする。
この閾値は実績に基づくベンチマークではなく、今回の実験の判断用に置く。
下回る場合は、問い・本文・導線を見直してから1テーマだけ再検証する。
再検証後も関係操作がほぼ使われなければ拡張を止め、静的な読み物に簡素化する。
entry-sharedとコピー/API操作件数は補助指標。共有完了や共有の因果効果とは呼ばない。
閲覧が集まらない場合は機能の需要を判定できない。検索流入と紹介導線を先に検討する。
SNS投稿・連絡・広告出稿は実施していない。

## 戻し方

この変更のコミットを戻し、既存の自己ホスト/Cloud Run更新手順で再起動する。
既存DB・要約キャッシュ・訪問集計は移行/削除していない。
関係の根拠が崩れた場合は該当HTMLの関係を撤去し、同じブラウザ検証を行う。
ページと計測パスを撤去しても、既存ログは元の保存期間で失効する。
