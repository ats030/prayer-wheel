各記事のディレクトリには、次の記録を残す。

- `packet.json`: モデルに渡した事実メモと出典。公開記事の完成本文は渡していない。
- `response.json`: Ollamaの元の応答。
- `draft.json`: 生成CLIが構造と参照を検証した下書き。
- `manifest.json`: モデル、digest、入力とプロンプトのhash、生成条件、生成統計。
- `reviewed.json`: 一次資料と照合して編集した、公開に使った本文。
- `editorial-changes.json`: 下書きからの変更前後と理由。
- `claim-audit.md`: 主張と一次資料の対応、対象範囲、断定できない事項。
- `publication.json`: 公開時の本文・応答・HTMLのhashと編集確認記録。

`manifest.json` の `editorial_review: pending` は生成時の状態を保持する。
公開前の編集確認は、別の `publication.json` に `completed` として記録する。
元のモデル応答や生成条件を、公開時の編集内容で上書きしない。
これらは運用記録で、公開サーバーの静的配信対象は `frontend/` のみである。

今回も参照IDの機械検証だけでは意味の誤りを取り除けなかった。
Ollamaだけによる無確認の自動公開や、一般的な執筆品質の同等性を示す検証ではない。
記事の末尾に、Ollamaのモデル名と出典照合後に編集したことを表示する。
旧本文はGit履歴に残り、公開URL・関係の固定ID・SEO・匿名操作計測は維持する。
