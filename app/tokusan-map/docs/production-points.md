# 産地の代表位置

`data/official.json` の産地、元の県庁座標、品目IDは保持する。
`data/production_points.json` に検証可能な代表点を記録し、DB生成時に適用する。
地域分類は元の産地を使い、代表点から品目の全産地を推定しない。

公的情報で主要産地を確認できた場合はそれを優先する。
今回の登録では生産量の順位を確定する情報がないため、出典の記載順で最初に
特定できる現行市区町村を選び、その役場位置を使う。
市町村の記載順を生産量の順位とは扱わない。
県全域と明記された品目、役場を一意に確定できない品目、現行市町村を
特定できない品目は、元の県庁座標と「都道府県代表位置」の注記を保つ。
役場が具体的な生産地区の中にあることは保証しないため、詳細に
「実際の生産地点ではありません」と表示する。
既存の市町村座標を持つ品目は変更しない。マーカーは一品目につき一つで、重なりはずらさない。

## 位置データの採用・利用条件

出典：国土交通省 国土数値情報
[市町村役場等及び公的集会施設（2022年4月）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P05-2022.html)。
2026-09-29にデータ詳細と[利用規約](https://nlftp.mlit.go.jp/ksj/other/agreement.html)を確認した。
配布ファイルは無料で取得でき、データ詳細の使用許諾条件は CC BY 4.0。
商用利用・加工・再配布が可能で、出典と加工した旨を詳細画面に表示する。
有料サービス、APIキー、追加の実行時依存は使わない。
元データが2022年4月基準であることを出典名に残し、現在の役場所在地を保証しない。

施設分類1のみを利用し、支所・出張所・公民館を除外する。
同じ市町村に複数の本庁候補がある場合は自動で選ばない。
位置は JGD2011 の経緯度。抽出時に施設名・行政区域コード・住所を保持し、
DB生成時に産地名との対応と都道府県境界を検証する。
全国ZIPのSHA-256を記録して再現性を確保する。

```sh
python3 scripts/import_production_points.py --archive /path/to/P05-22_GML.zip
python3 scripts/build_db.py
python3 scripts/verify_catalog.py
```

DBとAPIには `coordinate_kind`, `coordinate_label`, `coordinate_source_url`,
`coordinate_source_name` を追加する。`prefecture_level` は県庁座標を使うかどうかを表し、
産地の地理的な範囲を表すフラグとしては使わない。
座標修正を戻す場合は代表点登録と同一変更のDB・サーバーを一緒に戻す。
