# 品目写真

全651品目が写真欄の対象です。`frontend/images.json` の確認済み写真を優先し、
未登録のWikidata品目は既存の `/api/wikiimage?qid=Q…` を使います。
公式品目に架空のQIDを付けません。既知の誤写真や許諾不明の候補は旧経路でも表示しません。
写真登録が取得できない場合も一覧・地図は利用でき、写真欄から再試行できます。

2026-09-29の監査では、旧P18/P373経路で画像URLとライセンスを解決できる候補は119/651件
（18.3%）でした。本文の複数画像、別表記、Commonsの個別検索と専用カテゴリを調査し、
確認済み登録を229件（35.2%）から326件（50.1%）へ増やしました。
追加97件（Commons 56件、農林水産省の許可済みZIP写真41件）です。
公式品目の写真は102件から185件へ増えました。
既存229件の写真URL・帰属・説明はすべて保持しています。
これはメタデータと品目対応の確認率であり、利用者の回線での画像ダウンロード成功率ではありません。
集計と未登録理由は `data/images.json` に保存しています。
同日のHTTP検査では、登録326件すべての画像URLが画像として成功応答しました。

写真候補は既存curationの記事タイトル、公式品目の同名記事、WikidataのP18/P373に加え、
記事本文の複数画像、Commonsの品目名検索・英語名検索・専用カテゴリです。
候補の検索結果を自動公開しません。追加写真は `image_review.json` の `approved_photos` に
品目ID、ファイル名、照合根拠、根拠URL、必要な写真説明を記録してから登録します。
ファイル単位の誤画像除外を優先し、追加写真も同じ個別ライセンス検査を通します。
地域差で除外された料理も、正しい地域の実写を別途確認できた場合だけ承認できます。
例えば熊本だご汁には熊本県阿蘇市の実写を登録し、大分だんご汁の代用を防いでいます。
ブランドや産地を確認できない一般食材の参考写真は追加していません。
本文記事の写真を優先しますが、転送先が一般的な食材、地名、別の料理であれば採用しません。
許可する別名、除外ファイル、地域による料理の取り違えは `data/image_review.json` に記録します。
自治体庁舎、店舗外観、食品レプリカなどで件数を増やしません。
茶畑や実際の制作工程など、品目に対応する写真には内容の説明を付けます。

各画像に作者・クレジット・指定された帰属表示、ライセンスへのリンク、取得元の出典を表示します。
Commonsはファイルページ、農林水産省は当該料理ページへリンクします。
農林水産省の写真は通常掲載写真と区別し、当該品目・県のページで
許可なく使用できると明示されたZIP配布分だけを採用します。
第三者提供写真やZIPのない画像は、この方法では登録しません。
`data/maff_images.json` に品目名、県、許可文、配布ZIP、取得日、ページ・ZIP・原本のhashを保存し、
`frontend/photos/maff/` にZIP内の原本を加工せず保存しています（41枚、25.4 MiB）。
更新時は専用URLとファイルhashを検証し、既存のCommons写真を上書きしません。
利用条件は [tool-license-maff-photos.yaml](tool-license-maff-photos.yaml) に記録しています。
許諾範囲は [tool-license-photos.yaml](tool-license-photos.yaml) に記録しています。
元画像の加工はしません。縮小画像の読み込みが失敗した場合だけ、同一ファイルの元画像を試します。
APIの正のキャッシュは7日で更新し、失敗した画像はキャッシュから削除します。
失敗を永続キャッシュせず、写真欄の「再読み込み」から再試行できます。

更新時は以下を実行し、候補の品目対応と写真の内容を確認してから公開します。
新しい監査では別のキャッシュディレクトリを使い、`image_review.json` の確認日も更新してください。

```sh
python3 scripts/find_image_candidates.py --search --output /tmp/tokusan-photo-candidates.json
# 候補の内容と権利を確認し、承認を data/image_review.json に記録する
python3 scripts/build_maff_images.py --cache /tmp/tokusan-maff-photo-cache
python3 scripts/build_images.py --cache /tmp/tokusan-photo-cache
python3 -m unittest discover -s scripts -p 'test_*.py'
```

API応答はリポジトリ外に保存します。50件ごとの照会、maxlag=5、429/503の再試行と
識別可能なUser-Agentを使います。Commons画像は外部URLを使います。MAFFの許可済みZIP写真は原本を保存して配信します。
登録データ、審査記録、公開JSONは一緒にコミットします。
