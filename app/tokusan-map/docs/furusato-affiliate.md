# ふるさと納税のリンク

## 現在の動作

詳細パネルから楽天市場の検索結果へ移動します。
検索語は「ふるさと納税 特産物名 都道府県」です。
特産物名か都道府県が空ならリンクを表示しません。
正式HTMLを登録した品目では、登録済み公開サイトで楽天アフィリエイトリンクを表示します。
登録先: https://tokusan-map-736831430371.asia-northeast1.run.app/
現在の登録は「夕張メロン（北海道）」の1件です。
他の品目や登録先以外の画面、登録データを取得できない場合は通常検索リンクです。
別産地の商品や通常商品も含まれるため、返礼品の存在や産地の一致は保証しません。

## 正式リンクの登録

1. 運営者が[楽天アフィリエイト](https://affiliate.rakuten.co.jp/)に登録し、掲載する公開HTTPSサイトをサイト情報に登録します。
2. 実際の検索結果URLを[公式のURLからリンク作成](https://affiliate.rakuten.co.jp/guides/link/)に入力し、テキストリンクを発行します。
3. `frontend/furusato-affiliate.json` の品目IDをキーに、`label`（品目名）、`prefecture`（都道府県）、`html`（生成ソース全文）を保存します。
4. 公式生成されたテキストリンクであり、検索先がその品目名と県の検索結果に一致することを検証します。PC・スマホで広告表示と元のURL・属性を確認します。

楽天の[ガイドライン](https://affiliate.rakuten.co.jp/guideline/rule/)は、発行されたURLの変更と、編集可能と明記された部分以外のHTMLやタグ属性の変更を禁止しています。
一つのURLから検索語を差し替えるテンプレート方式や、Amazon用の設定の流用は行いません。
現在はユーザーが提供した公式生成HTMLを保存・検証して、そのまま掲載します。
検証対象は単一のテキストaタグ、楽天のHTTPS広告URL、正しい品目と県の検索先、許可した属性です。
イベント属性や子要素、別の品目・県の検索先などは受け入れません。
広告であることと報酬を得る旨はリンクタグの外に表示します。
登録・サイト情報の設定・リンク発行は運営者のアカウントで行う操作です。
2026-10-06、運営者から楽天登録・公開サイト登録の完了報告と夕張メロンの正式HTMLを受領しました。
成果報酬の計測・承認は楽天側の処理であり、掲載確認だけでは報酬発生を確認できません。

## 検証と戻し方

通常リンクは外部APIへのアクセスや新規依存を必要としません。
検索語、HTTPSの遷移先、空データ時の非表示を検証します。
広告リンクの導入時には最新の規約を再確認します。
広告を停止するには `frontend/furusato-affiliate.json` の該当エントリーを削除します。通常検索に戻ります。
検索導線全体を停止するには `frontend/app.js` の `furusatoLink(o)` 呼び出しを削除します。
