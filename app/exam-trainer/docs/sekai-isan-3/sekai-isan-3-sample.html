国際自然保護連合（IUCN）の役割について、正しいものはどれか。

解説

問1　正解：A 世界遺産委員会に協力し、各国から推薦された自然遺産の調査や評価を行う

IUCNは、各国から推薦された自然遺産の調査や評価を行い、世界遺産委員会に協力しています。

参考 [S001]：世界遺産用語解説

問2　正解：A ICOMOSとIUCN

抜粋によれば、文化遺産はICOMOSに、自然遺産はIUCNに専門調査を依頼することになっています。

参考 [S002]：世界遺産登録までの流れ

問3　正解：C ⑥普遍的意義を持つ事象との関連

抜粋において日光の社寺の登録基準は「①人間の創造的才能を表す傑作」、「④歴史的時代の典型例」、「⑥普遍的意義を持つ事象との関連」であると記載されています。

参考 [S003]：【国別】旅好き夫婦が世界遺産巡りをおすすめ！ - いちごバターブログ

問4　正解：D 1972年

抜粋には、1972年の第17回ユネスコ総会において「世界の文化遺産および自然遺産の保護に関する条約」が採択されたと記述されています。

参考 [S005]：世界遺産の基礎知識 [世界遺産] All About

問5　正解：C 国際自然保護連合（IUCN）

抜粋によれば、自然遺産の現地調査と勧告は国際自然保護連合（IUCN）が担当します。

参考 [S006]：世界遺産 - Wikipedia

解説

問6　正解：C ユネスコによって1959年に設立された国際的政府間機関である

ローマセンターは、1959年にユネスコによって設立された国際的な政府間機関です。

参考 [S001]：世界遺産用語解説

問7　正解：A 10年ごとに見直し、再提出することがのぞましいとされている

抜粋では、暫定リストは10年ごとに見直し、再提出することがのぞましいとされており、不登録決議されたものの掲載継続は原則として認められず、推薦数は1年に1件までです。

参考 [S002]：世界遺産登録までの流れ

問8　正解：A ①人間の創造的才能を表す傑作

ル・コルビュジエの建築作品の登録基準として、①人間の創造的才能を表す傑作、②価値観の重要な交流、⑥普遍的意義を持つ事象との関連が挙げられています。

参考 [S003]：【国別】旅好き夫婦が世界遺産巡りをおすすめ！ - いちごバターブログ

問9　正解：D 奄美大島、徳之島、沖縄島北部及び西表島

暫定リストにある候補地のうち、「奄美大島、徳之島、沖縄島文化遺産および西表島」のみが自然遺産として記載されています。他の選択肢はすべて文化遺産として記載されています。

参考 [S005]：世界遺産の基礎知識 [世界遺産] All About

問10　正解：D 危機遺産リストに登録され、国際的な協力を仰ぐ

抜粋によれば、潜在的ないし顕在的に保存することが脅威にさらされている遺産は、危機遺産リストに登録されることで国際的な協力を得ることになります。

参考 [S006]：世界遺産 - Wikipedia
