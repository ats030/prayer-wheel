# 問題の品質診断

管理者の「品質診断」から手動実行する。問題バンクと7教材を同時に保存し、同じ検定・設問・選択肢・正解・解説の完全一致コピーは1問として評価する。登録先、由来、参照本文、取得日、教材JSONのSHA、評価基準の版、モデル名、実行条件を保存する。学習履歴・採用状態・販売承認は変更しない。

形式と引用照合は機械検査、正解・一意性・解説・誤答・範囲・日本語・意味的重複は既存ローカルモデルで評価する。モデル出力の必須項目、型、対象ID、判定を厳密に確認する。根拠引用が評価に渡した本文に存在しない場合、正解と一意性は判断不能とする。根拠要約は参照本文に代用しない。

保存済み本文は現在のキャッシュであり、生成時の本文と同じとは限らない。モデルに渡す本文は引用付近の最大1,200文字、最大2件に限定し、3問ずつ評価する。問題全体の真偽を保証する仕組みではない。意味的重複は同じ検定の文字列近傍3問との比較で、全組み合わせではない。

出典・分野・正解位置の分布も表示する。級に対する難易度、公式範囲への網羅性、出典の鮮度・矛盾、選択肢順による評価変化、生成モデル自身による評価の偏りは追加の確認候補とする。分布の偏りだけで不良とは判定しない。

失敗や情報不足は判断不能として残す。内容評価が3バッチ連続で失敗した場合、残りの内容評価を止める。途中結果は保存され、再起動後に未処理の問題から再開する。評価基準の版が変わった場合は新規診断が必要。初回評価前にモデルのdigestも記録する。取得できない場合はその状態を残す。同名の重みの差し替えを防ぐ仕組みではなく、同一結果の再現は保証できない。

## 人による確認

検定・由来・自動判定の組から順に最大30問を固定乱数で抽出する。確認CSVの `human_verdict`（pass/fail/unknown）、`reviewer`、`notes` だけを記入して取り込む。問題・自動判定の列の変更、異なる診断・版、重複行は拒否する。CSVは2MB以下。表示・ダウンロード・取込には管理者認証が必要。

問題や出典が変わった評価には「過去の評価」を表示し、新しい人の確認は拒否する。比較可能な確認について、自動合格・人が不良の見逃し、自動不良・人が合格の誤排除候補、不一致、自動判断不能を数える。この標本から全問題の不良率は推定しない。人の確認がない段階で評価精度を公表しない。

## 運用と切り戻し

ローカルOllamaの既存モデルを使い、共有プロキシにはバックグラウンド処理として分類する。別サービスや依存は追加しない。診断を止めるにはアプリを停止し、バックアップから戻す場合はSQLite全体を復元する。コードだけ切り戻す場合、専用の quality_run / quality_item / quality_review テーブルは残しても学習機能には影響しない。
