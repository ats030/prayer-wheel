# 考古教材の販売準備

対象は考古検定の入門クラスを目指す学習者。
四択50問と全問解説を収録したPDFを500円で販売する。
無料体験10問は有料PDFにも含め、追加40問と印刷して解き直せる構成を購入価値にする。

現段階では未校閲。
ページは既存の管理者ログインを利用したプレビューに限る。
一般利用者には404を返し、プレビューにはnoindexを指定する。
通常の問題バンクと解答履歴は変更しない。
PDFや教材の元データは静的配信しない。

## 制作物の検証

`PYTHONPATH=app/exam-trainer/src .venv/bin/pytest app/exam-trainer/tests -q`で学習機能と教材の公開制限を検証する。
`/home/ats030/.venv/bin/python app/exam-trainer/scripts/check_kouko_browser.py`で一時的な教材コピーを使い、PCとスマホ幅、採点、再試行、解き直し、キーボード操作を確認する。
ライブサービスと校閲承認は変更しない。
スクリーンショットは`/tmp/kouko-390.png`などへ出力する。

## 校閲と出品

1. 校閲用PDFを読み、各問の正解、誤答選択肢、解説、対象クラスへの適合を参考資料と照合する。対応するCSVに校閲者、結果、修正理由を残す。
2. 修正を教材の元データに反映し、`/home/ats030/.venv/bin/python app/exam-trainer/scripts/build_kouko.py`で原稿とPDFを再生成する。内容が変わると新しい校閲CSVが作られ、既存の記録は上書きされない。
3. 全問の校閲と参照先の利用条件の確認後、`kouko-release.json`へ確認した教材のSHA-256、校閲者、確認日、`source_terms_checked: true`を記録する。出典の`rights_status`は個別の確認結果へ更新し、その変更も含めた最終ハッシュを記録する。
4. PDFを再生成し、校閲用表示が消えたことと改ページを最終確認する。BOOTHの商品説明から準備用の文言を取り除き、校閲後の見本と販売用PDFを添付して出品する。
5. 実際の商品URLを`kouko-release.json`の`booth_url`へ設定する。HTTPSのBOOTH商品ページURLだけが購入リンクとして表示される。

校閲承認後、アプリの再起動で紹介ページと無料体験を一般公開できる。
商品URLが空の間は「販売準備中」と表示する。
教材の内容を編集するとハッシュが変わり、一般公開は再び停止する。
撤回する場合は`reviewed_sha256`を空にして再起動する。
BOOTHの出品状態は別途ショップ側で管理する。

## 集客導線

検索やSNSの一問解説から紹介ページへ誘導する。
紹介ページで対象者と内容を伝え、登録不要の無料10問へ進んでもらう。
解答後に正誤、解説、参考資料を表示する。
終了画面では間違えた分野を示し、見本とPDFの案内へつなぐ。
見本は無料10問と同じ内容に限定する。

購入案内は各解説の末尾と終了画面に置く。
追加40問の答えは体験ページや解答APIへ配信しない。
BOOTHが決済とダウンロード配布を担い、購入者アカウントや独自決済は実装しない。

## 公開先と計測

検索集客には、検索エンジンが到達できるHTTPSの公開URLが必要。
現在のローカルサービスを外部から利用できるとは確認していない。
紹介ページの最終URLが決まってから、商品説明とSNS原稿へ記入する。
SNS投稿やBOOTHへの出品はまだ実施していない。

visit-logの既存タグでページ閲覧を記録する。
体験開始ページと見本ページの閲覧数は見られるが、体験完了イベントや購入完了の自動計測は今回追加していない。
売上と購入件数はBOOTHの実績を基準にする。
閲覧数だけで購入率や体験完了率を推定しない。

価格500円は需要検証の仮価格。
BOOTHが2025年10月28日に案内した利用料5.6%＋45円に基づくと、1件のサービス利用料は73円、差引額は427円。
振込費用、税、制作費などは別であり、利益額とは区別する。
出品時には現行の料金を再確認する。
根拠：[BOOTHの料金改定案内](https://booth.pm/announcements/832)。
